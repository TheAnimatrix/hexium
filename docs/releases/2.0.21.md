## HEX 2.0.21

- Website-aware modes fail closed when Brave tab inspection fails instead of
  retaining and applying a stale domain. Configured hosts remain exact, so
  `www.example.com` is no longer silently changed to `example.com`.
- The official `hex-personal-commands` agent skill can now be installed from
  the HEX repository to help coding agents safely configure custom voice
  commands and transcript transformations.
