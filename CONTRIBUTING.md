# Contributing to Hexium

PRs are welcome. Keep them small and focused and we'll merge them fast.

- Bugs and ideas: open an issue, or just send the fix.
- Build it yourself: see [`AGENTS.md`](AGENTS.md) and [`docs/`](docs/README.md).
- Every PR runs **Hexium check** (format, tests, goldens, a real dictation).
- Hexium follows [Hex](https://github.com/anomalyco/hex) weekly. Changes that
  belong in Hex itself are best raised there as an issue, so both benefit;
  Hexium-only changes stay small so the weekly sync keeps applying cleanly
  (see [`hexium/README.md`](hexium/README.md)).
